# Production quality gates
- OIDC authentication and authorization
- Dependency scanning, SAST, SBOM, secret scanning
- OpenTelemetry traces, structured logs, metrics and alerting
- Offsite encrypted backups and tested restore
- CI, integration/E2E tests, branch protection
- TLS, privacy, audit logs, rate limiting
- Container deployments and rollback

These gates are planned, not implemented. Git data storage is not suitable for high-concurrency or sensitive transactional data.
